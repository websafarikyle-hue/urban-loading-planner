# 城市共配 PRD v0.9

前一天接到若干杭州方太门店的次日补货订单，每单包含门店、收货开始与卸货完成截止、箱型及数量。调度员确认车队与规则后，生成分车、道路配送顺序、三维装载和逐站卸货执行单。公开门店仅提供演示地点，订单、包装、车辆与费用为模拟或用户录入，不代表真实传化客户。

| 用户要求 | v0.9行为 |
|---|---|
| 免费地点选择 | 20家同品牌公开门店下拉，导出带来源的编号表 |
| 模拟次日接单 | 可复现种子，在12～16家门店生成订单 |
| 多种货物及配件 | 烟机、灶具、洗碗机、烟管配件、安装辅料五种模拟箱型 |
| 产生真实计算的堆叠 | 比较平铺与紧凑布局，校验上层完整支撑、承重及取货通道 |
| 不先抽走下层 | 每步重放检查剩余支撑，先取上层或挡货，再卸本站并恢复搬移货物 |
| 卸货耗时估计 | 准备＋逐箱＋易碎＋重货＋搬移与恢复，计入时间窗和人工费 |
| 三种终点 | 回仓、末站结束、指定停车点 |
| 两种卸货规则 | 直接取货；有限搬移，默认每站最多2件，可设0～5 |
| 最多出车数可设 | 从全部启用车辆池中选择，最大6辆 |
| 两种优化目标 | 服务量优先，然后车辆作业时间之和最小或费用最低 |
| 默认费用且可改 | 小、中、大车型分别有默认费率；可逐车编辑或统一应用 |
| 弯曲路径与对应时间 | 免费OSRM普通驾车模型；匹配分段距离及时间，更新提示重算 |
| 不考虑堵车限行 | 本版优化不纳入这些条件 |
| 比较方案可解释 | 输入顺序、最近门店、最早截止三规则与联合优化，统一约束 |
| 可直接使用的页面 | 桌面/手机布局、说明页、CSV导入、场景保存、JSON导出和打印执行单 |
| 独立发布 | GitHub Pages访问无需ChatGPT登录，另有单文件HTML下载版 |

输入上限30单、150箱、6辆车；单仓、单日、一次出车，一单同车整单配送。最多两层、单箱完整支撑、保持直立并轴向装卸；搬移假设现场有临时放置空间。大模型助手后续迭代。

编辑先产生草案，确认才重算；旧结果与执行单绑定上次确认输入。导入失败、网络失败及过期请求不覆盖有效数据。道路路径缺少匹配数据时为虚线示意，普通驾车估计不是实测耗时。

总作业时间为各车装车、行驶、等待、卸货及终点行程之和；整批任务历时单独显示。本版时间目标优化前者，尚无最晚结束时刻最小目标。搜索有预算与45秒前端超时，不证明全局最优，启发式未安排不等于数学不可行。

验收包含常规样例、堆叠压力样例、有限搬移样例及12种条件组合，数据见 `v09-results.json`，测试范围见 `v09-validation.md`。
